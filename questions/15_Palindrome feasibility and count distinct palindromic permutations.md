Coding Interview Question

You are given a string s consisting of lowercase English letters.

Your task has two parts:

1) Palindrome Feasibility
Determine whether any permutation (rearrangement) of the characters of s can form a palindrome.

2) Count Distinct Palindromic Permutations
If a palindrome can be formed, compute the number of distinct palindromic strings that can be generated using all characters of s.
If it cannot form a palindrome, return 0.

Notes

- A palindrome is a string that reads the same forward and backward.
- Different character arrangements that produce the same palindrome should be counted only once.
